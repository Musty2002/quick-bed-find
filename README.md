# HospitalManagement System

A cloud based hospital management system that moves a patient through one connected workflow: **Records → Doctor → Laboratory → Accounts**, with an **Admin** managing staff and their roles.

Built for the Federal University Dutse final year project (B.Sc. Software Engineering) and deployed on Lovable Cloud.

**Live app**: https://hospitalmisnura.lovable.app

## Roles

| Role | Workspace | What it does |
| --- | --- | --- |
| Records | `/records` | Registers patients (each gets a hospital number such as `HMS-70848D`) and sends them to a doctor with the complaint. |
| Doctor | `/doctor` | Works the waiting queue, writes diagnosis and notes, requests lab tests, issues prescriptions, completes the visit. |
| Laboratory | `/lab` | Sees requested tests, enters results — they appear back on the doctor's screen. |
| Accountant | `/accounts` | Bills a visit, records each item as paid by cash or transfer, shows totals collected and still owed. |
| Admin | `/admin` | Creates staff accounts, turns roles on or off per person, and sees hospital-wide figures. |

One person can hold several roles; the navigation only shows the desks they are allowed to open.

## Patient flow

```text
RECORDS registers patient  →  DOCTOR consults, tests, prescribes
        →  LABORATORY enters results  →  ACCOUNTANT bills and receives payment
                    ADMIN manages staff accounts and role access
```

## Tech stack

- **React 19 + TypeScript** on **TanStack Start** (file-based routing, server functions for privileged actions)
- **Lovable Cloud** backend: PostgreSQL with row-level security, email/password auth
- **Tailwind CSS v4** with a blue-and-white clinical design system and motion utilities
- **Vite** build tooling, **ESLint** + **Prettier**, **bun** or npm for packages

## Project layout

```text
src/
  routes/

    _authenticated/       role workspaces: records, doctor, lab, accounts, admin
  components/             AppHeader (sidebar + mobile menu), StaffShell, ui/
  lib/
    roles.ts              role definitions, currency helper
    hms.functions.ts      admin-only server functions (create staff, set roles, delete)
  integrations/supabase/  generated client — do not edit by hand
  styles.css              design tokens, motion utilities
supabase/                 backend configuration and migrations
```

## Development

Requires Node.js — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd hospital-management-system
npm i
npm run dev
```

Then open the local preview. Useful scripts:

```sh
npm run dev       # start the dev server
npm run build     # production build
npm run preview   # serve the production build
npm run lint      # ESLint
npm run format    # Prettier
```

Environment values (`VITE_SUPABASE_URL`, publishable key, project id) are generated by Lovable Cloud and kept in `.env`.
